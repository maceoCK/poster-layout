# poster-layout

A taste skill for Claude Code: what a good poster looks like, shown through real work rather than rules. 510 posters from a Pinterest board plus 25 canonical posters, sorted into 14 looks.

```bash
git clone https://github.com/maceoCK/poster-layout ~/.claude/skills/poster-layout
```
